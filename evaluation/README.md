# Evaluation materials

The final [English live tests, 1 November 2026](english-live-tests-2026-11-01/README.md) contain three completed sequential tests, actual answer excerpts, nine screenshots and a Word report. They establish functional execution, not independently verified legal correctness. The user-supplied original contract is included unchanged in the final package’s `inputs/` folder; see its provenance note.

The `case-01`, `case-02`, and `case-03` folders are earlier unexecuted templates using synthetic `examples/` inputs. They are not the live test evidence. The latency benchmark uses simulated I/O, not a live model.

Current input for future runs: [English used-vehicle agreement](english-live-tests-2026-11-01/inputs/Used%20Vehicle%20Sale%20and%20Purchase%20Agreement%20English.docx). Existing live evidence used the historical Chinese input; the English-input rerun is pending.
