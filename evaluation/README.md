# Evaluation materials

The final [English live tests, 1 November 2026](english-live-tests-2026-11-01/README.md) contain three completed sequential tests, actual answer excerpts, nine screenshots and a Word report. They establish functional execution, not independently verified legal correctness. The exact filled contract used in the run is still needed; see the root README.

The `case-01`, `case-02`, and `case-03` folders are earlier unexecuted templates using synthetic `examples/` inputs. They are not the live test evidence. The latency benchmark uses simulated I/O, not a live model.
