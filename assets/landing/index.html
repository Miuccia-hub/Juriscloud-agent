功能设置如何使用

让合同里的问题，
变得清晰。

从商业合同审查，到条款背后的判例与法律依据。上传材料，在一段对话里继续深入。

了解功能

维多利亚州与中国大陆，分别审查。

从读懂合同，
到找到下一步。

为律师、法务与法学生设计，让文本审查和法律研究衔接起来。

01

审查商业合同

上传 Word、文字版 PDF 或文本文件，分析法律效力、文本完整性、商业风险与待核实事项，获得表格化发现和修改建议。

采购、合作、咨询、技术开发、保密与知识产权等合同。
02

围绕条款检索类案

结合上传合同和所选司法区域，检索相关判例与法律规定，查看来源，并区分文本判断与需要进一步核实的法律结论。

当前检索围绕上传合同展开，需先提供合同材料。
03

先审合同，再继续追问

针对某个条款、风险或修改建议继续提问，也可以补充事实，让后续研究延续当前合同的上下文。也可以追问相关案例；选择中国大陆并启用北大法宝后，优先通过北大法宝进行类案检索。

在页面内查看结果，也可导出审查报告与已采纳的修订。
设置

让审查，
更贴合你的需要。

进入工作台后，点击左侧栏底部的“设置”，选择语言与审查立场，再连接自己的模型账户。

界面语言与回答语言分别设置；上传文件的原文不会随界面语言改变。

界面语言
选择中文或英文，切换导航、按钮和操作提示。
输出语言
跟随问题语言，或指定中文、英文、中英双语。
审查立场
填写你代表的交易方，例如采购方、供应商或顾问；未指定时中立审查。
你的 API Key
展开“模型与接入”，输入自己的 API Key。密钥仅用于当前会话，可通过“测试分析模型连接”检查接入。
模型选择
分别选择分析模型与联网模型：gpt-6-luna 或 gpt-6.1-sol。实际可用性取决于接口和账户权限。

带上合同，
从一个问题开始。

选择司法区域，上传合同并输入关注点。收到审查结果后，直接在底部输入框继续追问。

  1. 选择范围

    维州或中国大陆；可指定审查立场与回答语言。

  2. 上传并提问

    添加合同及必要补充资料，输入你的问题。

  3. 审查与深入研究

    阅读风险表格、核对来源，继续追问或导出结果。
